# RepoRacer Next.js Demo

Small example project shape for trying RepoRacer against a Next.js app.

```bash
pnpm install
pnpm test
npx reporacer init
npx reporacer run --agents fake-success,fake-noop --tasks 1
```

The dependency pins were checked with `npm view next version`, `npm view react version`, and `npm view react-dom version`.
