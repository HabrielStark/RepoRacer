# Code of Conduct

RepoRacer follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project harassment-free for everyone.

## Expected Behavior

- Be respectful and direct.
- Assume good intent, but accept correction.
- Keep technical disagreement focused on evidence.
- Respect privacy around proprietary code, benchmark outputs, logs, and security reports.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private code, secrets, reports, or vulnerabilities without permission.
- Sustained disruption of issue, pull request, or release work.

## Enforcement

Maintainers may remove comments, close issues, block users, or restrict participation when needed to protect the project and its contributors.

Report security issues through private security advisory channels. Report conduct issues through the repository maintainers once a public repository owner is configured.
