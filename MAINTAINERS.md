# Maintainers

RepoRacer is maintained by:

| Role             | Maintainer                                                                                      | Scope                                                                                             |
| ---------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Project owner    | [@HabrielStark](https://github.com/HabrielStark)                                                | Repository ownership, release approval, security triage, npm ownership, and roadmap decisions     |
| Release manager  | [@HabrielStark](https://github.com/HabrielStark)                                                | Version tags, npm provenance publish, GHCR image publish, GitHub Releases, and changelog accuracy |
| Security contact | [GitHub Security Advisories](https://github.com/HabrielStark/RepoRacer/security/advisories/new) | Private vulnerability reports and coordinated disclosure                                          |

Maintainers are responsible for:

- reviewing RFCs that affect public behavior;
- keeping CI, provenance, release notes, and package metadata accurate;
- rotating or revoking exposed secrets;
- enforcing DCO sign-off and code-of-conduct moderation;
- maintaining the compatibility matrix for official agent presets.
