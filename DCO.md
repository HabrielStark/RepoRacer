# Developer Certificate of Origin

By contributing to RepoRacer, you certify that you have the right to submit the contribution under the project license.

Use signed-off commits:

```bash
git commit -s
```

The sign-off line is:

```text
Signed-off-by: Your Name <you@example.com>
```

RepoRacer follows DCO 1.1: https://developercertificate.org/
