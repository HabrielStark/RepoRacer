# Examples

RepoRacer ships one benchmark-style fixture and three small language smoke projects.

![RepoRacer benchmark race visualization](../assets/reporacer-hero.png)

## Buggy Todo App

Generate a disposable git repository with an initial commit plus ten fix commits:

```bash
node examples/buggy-todo-app/scripts/create-history.cjs
```

Run the generated app's own test suite:

```bash
node examples/buggy-todo-app/generated/test/todos.test.cjs
```

Run RepoRacer against that generated history:

```bash
cd examples/buggy-todo-app/generated
node ../../../dist/cli.js init
node ../../../dist/cli.js tasks --tasks 2
node ../../../dist/cli.js run --agents fake-success,fake-noop --tasks 1 --json
```

## Language Smoke Projects

```bash
node examples/nextjs-demo/test/home.test.cjs
python -B -m unittest discover -s examples/python-demo/tests
cargo test --manifest-path examples/rust-demo/Cargo.toml
```

## Demo Site

The release demo site is generated by:

```bash
pnpm demo:build
```

The generated site includes the docs and a static public report demo.
